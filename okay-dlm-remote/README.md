# okay-dlm-remote

The model's remote backends: TypeSafe's Jev and Convai's Laya as a `Judge` over the one System One wire they both speak, an OpenAI-shaped embeddings wire as an `Embedder`, and the `Wire` seam they post through — faked in every test. Ours stays the default in okay-dlm; this is what a `given` names (specs/dlm.md, "Backends").

**Depends on:** `okay-dlm`

This page is a pointer, not a guide: the module's own doc
below carries the pieces, the decisions and the measurements.
