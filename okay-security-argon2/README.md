# okay-security-argon2

The one satellite that buys a dependency (specs/security.md, stage 5): Argon2id via Bouncy Castle, because a memory-hard KDF cannot be had from the JDK — and a separate module keeps okay-security's zero. Services opt in by classpath.

This page is a pointer, not a guide: the module's own doc
below carries the pieces, the decisions and the measurements.
