# the i18n seam — every language on the element

The container's own `Inline` carries this now (specs/site-framework.md
stage 3): the element renders the request's language and holds the
others, and the client switches with no round trip.

```scala declare
import okay.script.api.Inline

val langs = Inline.Langs.of("pl", "en", "uk", "ru")

def i18nAttrs(ru: String, pl: String, en: String, uk: String): String =
  Inline.attrs("ru" -> ru, "pl" -> pl, "en" -> en, "uk" -> uk)
```
