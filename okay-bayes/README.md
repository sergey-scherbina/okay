# okay-bayes

Bayesian inference without Python: a model is a program that draws named random quantities and weighs its run by what it observed; a forward draw, likelihood weighting and Metropolis–Hastings are handlers over it. Measured against *Bayesian Methods for Hackers*.

**Depends on:** `okay` (core). Pure Scala — cross-built for JVM, JS and Native.
