# okay-blob

The object-store seam (specs/blob.md): bytes and streams in the engine, meaning at the edge — the trait three specs already assumed (persist offload, the lake roads, Arrow handoff). Keys are opaque strings with `/` as the conventional separator: the S3 model, which is the model.

This page is a pointer, not a guide: the module's own doc
below carries the pieces, the decisions and the measurements.
