# okay-js

JavaScript as a value: a typed tree, a printer, a macro that emits the text as a compile-time constant, and a `js { }` block that builds the tree from a deliberately small subset of Scala. Not a compiler — that is Scala.js, and this module says so when you leave the subset.

**Depends on:** nothing. Pure Scala — cross-built for JVM, JS and Native;

This page is a pointer, not a guide: the module's own doc
below carries the pieces, the decisions and the measurements.
