# okay-clojure

Interop with Clojure: call Clojure through its own Java API (`Clj`), and a `Stage` IS a Clojure transducer, both ways (`Transducers`). JVM; Clojure 1.12.

This page is a pointer, not a guide: the module's own doc
below carries the pieces, the decisions and the measurements.
