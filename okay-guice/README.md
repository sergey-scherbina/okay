# okay-guice

A Module's values as Guice bindings — by name from the plan, by type when unique — with the scope's closer bound beside them; an injector's instance as a module.

**Depends on:** `okay` (JVM), guice 7 (jakarta.inject).

This page is a pointer, not a guide: the module's own doc
below carries the pieces, the decisions and the measurements.
