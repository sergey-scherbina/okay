- [ ] proc-form-consumer — a FORM as a durable procedure (filed
      2026-09-18 by static-workflow-optics, which declined to tick a
      box it had not earned). `ui-direct-example` validates a form
      applicatively and puts each error back with an optic; the same
      form as a `Proc` would be a durable one — the user answers a
      field, closes the laptop, and the run resumes at the next field
      with the earlier answers in the journal. WHAT IS ALREADY PROVED,
      so the lane is a consumer and not machinery: an optic applies to
      a step with no new code (`TestProcOptics`), the journal holds
      only the step's answers, and a crash between two questions
      resumes with one activity repeated and no more (`TestProcCut`).
      WHAT IT WOULD DECIDE: whether a term reads well when the
      questions are a form's fields rather than a workflow's
      activities — which is the same question `okay-conf` decided for
      `Validated`, and the only kind of question a consumer can
      answer. TRIGGER: a UI lane that wants a form to survive a
      reload. DONE-WHEN: the form's fields are the term's leaves, a
      half-filled form is a journal, and `mermaid` draws it.
