# okay-cache

Caching with NAMED invalidation: every cache states at construction where its truth lives and how wrong it may be. There is no default TTL — the absence of that feature is the feature (specs/cache.md).

**Depends on:** the core only. Cross-built JVM/JS/Native.

This page is a pointer, not a guide: the module's own doc
below carries the pieces, the decisions and the measurements.
