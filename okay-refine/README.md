# okay-refine

Reading anything out of anything, one pattern at a time: a typed hierarchy of patterns (prisms whose read may decline) that recognise a document level by level and say why.

**Depends on:** `okay` (core), `okay-codec`, `okay-optics`. Pure Scala — cross-built for JVM, JS and Native.

This page is a pointer, not a guide: the module's own doc
below carries the pieces, the decisions and the measurements.
