## okay-model-spec - the plan for the Model Decision Runtime's open half

okay-watch's operator wrote the Model Decision Runtime (okay-watch
`specs/mdr.md`): an analyst's R or Python model run unchanged in
production, every decision recorded and reproducible. Its licensing seam
puts the runtime in the open and the regulated extras in okay-watch.

- specs/okay-model.md: what okay already has that MDR stands on, what
  okay-watch built first and moves here, the new modules (okay-model,
  okay-model-runtime, okay-model-spark, okay-model-cli, the analyst
  packages), the changes to existing modules (okay-arrow, okay-foreign,
  okay-r, okay-stream, okay-persist, okay-kafka), stages, the measurements
  each owes. The same file is in okay-watch. A plan, no code.
