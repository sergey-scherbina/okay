# the i18n seam — every language on the element

[esc](/lib/html.md)

```scala declare
def i18nAttrs(ru: String, pl: String, en: String, uk: String): String =
  " data-ru=\"" + esc(ru) + "\" data-pl=\"" + esc(pl) +
    "\" data-en=\"" + esc(en) + "\" data-uk=\"" + esc(uk) + "\""
```
