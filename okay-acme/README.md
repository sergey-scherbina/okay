# okay-acme

An ACME (RFC 8555) client: the protocol a certificate authority speaks to issue a certificate without a human — prove you control the name, get 90 days, renew before they run out. specs/acme.md holds the decisions.

This page is a pointer, not a guide: the module's own doc
below carries the pieces, the decisions and the measurements.
