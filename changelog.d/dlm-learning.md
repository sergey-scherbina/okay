## dlm-learning - the learning mode governed, audited, explainable, correctable (stage 1)

specs/dlm-learning.md, at the operator's word: learning that can be
controlled, audited, studied and corrected from inside and, under
rights, from outside.

- `Teaching`: own lessons, teachers, stewards, a kill switch per
  channel; ours is the narrowest and every channel on.
- `Ledger`: `Learned`, `Forgotten`, `Shared`, `Rebuilt`, `Refused` —
  append-only, `replay` is the memory fold, a JSON wire so a service
  journals them where it journals everything else.
- `Explanation`: why a decision, as a value — layer, rule verbatim,
  lesson and owner, everything noticed, the judge's ranking and name,
  encoder, tables by hash (`Exemplars.hash`).
- `Governed`: `route`, `explain`, `lessons`, `shared`, `ledger`;
  `teach`, `forget`, `share`, `rebuilt` — every refusal recorded. The
  invariant is the type: learning changes the memory fold and nothing
  else.
- Eleven tests, one per behavior line of the spec.
